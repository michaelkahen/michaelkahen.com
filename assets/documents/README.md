# Resume document

The public resume is stored at:

```text
Michael_Kahen_Resume.pdf
```

The Resume panel in `index.html` links to this exact case-sensitive filename for
viewing and downloading. Its URLs include a `?v=` version tag to prevent mobile
PDF viewers from reusing an older cached URL. Whenever the PDF changes, update
the version on every resume URL in `index.html` in the same change, following
the instructions in [AGENTS.md](../../AGENTS.md#resume-updates).
